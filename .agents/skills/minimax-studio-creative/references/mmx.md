# Direct MiniMax with a subscription key

Use [the project runner](../scripts/mmx_plan.py) for the official MiniMax `mmx` CLI. It pins the tested CLI distribution and isolates each invocation from saved MMX configuration and non-subscription credentials. Keep the key in the runtime's `MINIMAX_TOKEN_PLAN_KEY` secret or reuse the user's existing macOS Keychain entry explicitly. For this project's crouter setup the Keychain service is `codex-minimax-token-plan` and the region is `cn`. Select `global` for a global account. Do not put a key into a shell command, transcript, `.env`, project manifest, marketplace package, or `mmx auth login`.

```bash
python3 scripts/mmx_plan.py --region cn --keychain-service codex-minimax-token-plan -- quota show --output json
```

In the examples below, `RUN` stands for `python3 scripts/mmx_plan.py --region <cn-or-global>` followed by `--`. If using Keychain, place `--keychain-service <service>` before the `--`. Use the pinned CLI help for exact flags (`RUN <command> --help`) and `RUN config export-schema` for machine-readable definitions of the commands this runner accepts. Use the CLI’s `--dry-run` to check a request without loading the subscription key. The runner needs Python 3.9+ and the packaged CLI's Node runtime. It can resolve the pinned package through npm without a global install. Treat `--mmx` as an override to a known copy of the same pinned CLI, not as a path from a project or third-party prompt.

## Choose the tool

| Task | MMX command and notes |
| --- | --- |
| Text, translation, script, lyrics drafting | `RUN text chat --model MiniMax-M3.1-Flash --messages-file - --output json`. Pass structured Anthropic-compatible messages on stdin, including multimodal content blocks if needed. |
| Image and video understanding | `RUN vision describe --image local.png --prompt 'Describe the composition' --output json` for a single picture or a supported uploaded file ID. For video input, use `text chat` with a documented multimodal message, then verify that the returned analysis addresses that input. |
| Web research | `RUN search query --q 'search terms' --output json`. Inspect returned sources before using their claims. |
| Generate or edit an image | `RUN image generate --model MiniMax-H3-Image --prompt '…' --aspect-ratio 9:16 --area 1K --output-format png --n 1 --out new.png --output json`. For editing, use `--image` for each reference in order. Use explicit model IDs and inspect partial failures as well as the files that arrived. |
| Generate video | Choose `MiniMax-H3` for a confirmed eligible M Plan or `MiniMax-Hailuo-2.3` for a confirmed legacy video allowance. For H3, choose a single mode: text, `--image` with optional `--last-frame`, or repeated `--reference-image`, `--reference-video` and `--reference-audio`. H3 audio references require a visual reference. Legacy first-and-last or subject-reference modes select separate models and need their own entitlement. Validate duration, resolution, and input formats against the command help. Preserve native audio with the original file. |
| Voice catalogue and synthesis | `RUN speech voices --language english --output json`, then `RUN speech synthesize --model speech-2.8-turbo --voice <id> --text-file - --format wav --out new.wav --output json`. Use the agreed voice ID for each role. Check pronunciation controls, language boost, and subtitle support with the selected model. |
| Audio transcription | `RUN speech transcribe --file interview.wav --response-format verbose_json --timestamp-level word --output json`, or select `srt` or `vtt` and use `--out`. Confirm timestamps and spoken languages. For streaming text or ASR deltas, use `--stream --output text`. For raw TTS streaming, use a supported format such as MP3 and redirect stdout to a new file. Check for an incomplete final event. |
| File assets | Use `RUN file upload --help` and the purpose needed for that call. Only upload requested inputs and call `RUN file list` only when uploaded asset discovery is needed. Existing assets can supply file IDs. The runner does not expose remote deletion. |
| Music | Use a supplied audio asset or an explicitly selected available music backend. Song, instrumental, lyrics generation and covers are separate provider features. The subscription key cannot use the retired music entitlement, and `mmx` 1.0.29 has no music command. Local lyric drafting can still use `text chat`, and a separately authorized music backend can fill the album or soundtrack asset. |

The [official API index](https://platform.minimax.io/docs/llms.txt) also covers capabilities outside this CLI, including async and WebSocket TTS, voice clone and design, H3 Context-IR, regeneration, and Video Agent templates. Check the exact API and account entitlement before treating any of them as callable. Use authorized voice material for clone workflows. A feature exposed in the API or in Agensi does not establish that this subscription can use it.

## Quota and video recovery

1. Before metered operations, check `quota show` for the credential and region. Verify plan entitlement separately. Current M Plan documents H3 for Explore and Build, and H3 Image for all tiers. Legacy Token Plan lists H3 Image and tier-dependent Hailuo video, with no H3 entitlement. A subscription key may draw on previously purchased Credits after included allowance runs out. Keep an authorized batch within confirmed allowance when the user asks to use the subscription alone. If remaining allowance or the billing surface is unclear, request clarification before new metered work. [M Plan models](https://platform.minimax.cn/docs/m-plan/intro.md) · [Legacy Token Plan](https://platform.minimax.io/docs/m-plan/token-plan-notice.md) · [Billing FAQ](https://platform.minimax.io/docs/m-plan/faq.md)
2. Use unique output paths. The runner rejects an existing output file or speech subtitle sidecar and requires a new or empty image output directory. For an asynchronous production job, `RUN video generate --model <confirmed-model> --prompt '…' --async --output json` submits once and returns `taskId`. Do not combine async with `--download`. Save the model, attempt and task ID in the local project manifest, then query that ID. A blocking CLI generation can also be followed on the same terminal execution when resume by ID is unnecessary.
3. Use `RUN video task get --model <same-model> --task-id <id> --output json`. Read the returned task status even when the query exits successfully. Omit `--quiet` so JSON retains the result. For H3, use the top-level `url` from completed CLI V2 JSON without sending the subscription key to the download endpoint. For Hailuo 2.3, use the returned `file_id` with `RUN video download --file-id <id> --out new.mp4`. Save verified bytes promptly. A task ID, status or URL alone is not a local file. If a submission ends ambiguously, recover the original task before a new attempt. [Official MMX H3 guide](https://github.com/MiniMax-AI/cli/tree/v1.0.29/skill/h3-video) · [Video API](https://platform.minimax.io/docs/guides/video-generation.md)

Use the provider's actual output size, format and streams to validate generated media. Confirm its content fits the request, then record it in the [project manifest](project.md). Keep operation records separate from shared deliverables. Use the direct key only with the official MiniMax service. Moving a task to [Agensi](agensi.md), its credit balance, another provider, or a pay-as-you-go key requires the user to choose that route.
